# Manuscript package

The repository supports the manuscript:

**Compressing Exponential Weights for Online Logistic Regression: Exact Identities, Update-Closed Surrogates, and a Geometric Bottleneck**

The paper uses the repository as a reproducibility source for:
- exact score-identity checks;
- negative compression experiments;
- update-closed log-cosh software;
- adaptive localized quadrature;
- frozen one-dimensional validation artifacts;
- synthetic OGD/ONS benchmark snapshots.

The manuscript is deliberately claim-safe: the unrestricted multidimensional Hessian-metric volume/packing statement remains open and is not presented as a theorem.

Build requirements for the LaTeX submission package are pdflatex and biber. The package uses APA-style author-year references through biblatex.
