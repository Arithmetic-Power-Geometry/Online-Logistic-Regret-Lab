# Paper companion materials

This directory contains manuscript-facing metadata for the research project:

**Compressing Exponential Weights for Online Logistic Regression: Exact Identities, Update-Closed Surrogates, and a Geometric Bottleneck**

The repository provides the implementation and reproducibility materials used for:
- score-identity checks;
- negative compression experiments;
- update-closed log-cosh software;
- adaptive localized quadrature;
- one-dimensional validation;
- synthetic OGD/ONS benchmark measurements.

The unrestricted multidimensional Hessian-metric volume/packing statement remains open and is not presented as a theorem.

The submission package is designed for pdflatex and biber with APA-style author-year references.
