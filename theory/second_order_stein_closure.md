# Second-order Stein attack on Score Nullity

We test whether the first-score nullspace is closed by one more Stein identity.

For clarity take d=1 with Gaussian prior N(0,s^2), and observations on positive
directions v_j. Let

  q(theta) proportional to exp(-theta^2/(2s^2))
  product_j sigma(v_j theta)^{n_j+}
            sigma(-v_j theta)^{n_j-}.

Define

  p_j = E[sigma(v_j theta)].

The posterior score is

  S(theta)
  = sum_j v_j [n_j+ - n_j sigma(v_j theta)] - theta/s^2.

The zeroth test function phi(theta)=1 gives E[S]=0, i.e.

  sum_j v_j[n_j+ - n_j p_j] = mu/s^2.

This is the first-score equation.

## Test function phi(theta)=theta

Integration by parts gives

  E[1 + theta S(theta)] = 0.

Therefore

  1
  + sum_j v_j [n_j+ E(theta) - n_j E(theta sigma(v_j theta))]
  - E(theta^2)/s^2
  = 0.

Introduce

  q_j = E[theta sigma(v_j theta)],
  mu = E[theta],
  M2 = E[theta^2].

Then the second identity is

  sum_j v_j n_j q_j
  = 1 + sum_j v_j n_j+ mu - M2/s^2.

CRITICAL OBSERVATION:
this does NOT provide a second independent equation in the original predictive
unknowns p_j. It introduces new mixed moments q_j and M2.

Thus naive escalation of polynomial Stein test functions creates a moment
hierarchy rather than automatically closing Score Nullity.

## Alternative test function phi(theta)=sigma(v_k theta)

Stein gives

  E[v_k sigma(v_k theta)(1-sigma(v_k theta))]
  + E[sigma(v_k theta) S(theta)] = 0.

This introduces:
- E[sigma(v_k theta)^2],
- E[sigma(v_k theta)sigma(v_j theta)] for j != k,
- E[theta sigma(v_k theta)].

Again, the predictive first moments p_j are coupled to second-order nonlinear
moments rather than closed.

## Moment-proliferation principle

A finite-order Stein identity closes prediction only if the chosen test-function
family is invariant (or finitely closed) under multiplication by the logistic
score terms sigma(v_j^T theta) and differentiation.

For generic distinct logistic directions this family is not obviously finite:
differentiation produces sigmoid-polynomial terms and score multiplication
produces cross-products among directions.

This motivates a new structural quantity.

## Definition: Stein Closure Dimension (SCD)

Given a posterior family and a set of required predictive functions F_0, define
the Stein closure generated by a test-function class Phi as the smallest linear
space of expectation functions containing F_0 and all functions introduced by
repeated application of

  phi -> div phi + phi^T grad log q.

SCD_k is the dimension after k closure rounds.

If the closure stabilizes at dimension poly(d), exact or controlled approximate
prediction may be possible with compact state.

If SCD_k grows with the number of distinct adversarial directions, the score
route suffers moment proliferation.

This is a research definition, not yet a novelty claim.

## Small dependent dictionary V=[1,2]

First score:
  one equation for p_1,p_2.

phi=theta:
  one equation involving q_1,q_2,M2.

phi=sigma(theta):
  introduces E[sigma(theta)^2],
             E[sigma(theta)sigma(2theta)],
             E[theta sigma(theta)].

phi=sigma(2theta):
  introduces E[sigma(2theta)^2],
             E[sigma(theta)sigma(2theta)],
             E[theta sigma(2theta)].

So second-order identities do not algebraically close only on (p_1,p_2).
They enlarge the unknown expectation set.

## Consequence

Score Nullity is not killed merely by 'use the next Stein identity'.
The real question becomes whether the induced moment hierarchy admits a
finite-dimensional closure or a controlled approximation whose error is small
enough for logarithmic regret.

This is the next falsification target.
