# Corrective full-history compression accuracy audit

Suppose at every round t we can construct Q_t directly from a summary of the
FULL history so that its density-ratio oscillation relative to the exact
posterior P_t satisfies

  omega_t = osc(Q_t,P_t) <= c/t.

Then for any current likelihood L_t,

  |log E_Qt L_t - log E_Pt L_t| <= omega_t <= c/t,

and therefore cumulative approximation tax is O(log T).

This is valid because the CURRENT approximation is certified directly against
P_t; old approximation errors are not propagated.

## Potential approximation sufficient condition

If exact and surrogate posterior potentials F_t and Fhat_t satisfy centered
uniform error

  osc_theta(Fhat_t(theta)-F_t(theta)) <= c/t,

then the normalized density-ratio has the same oscillation, so omega_t<=c/t.

Thus the required aggregate historical potential accuracy is O(1/t), not the
O(1/t^2) used in the earlier conservative probability bridge.

## Log-cosh polynomial truncation

Historical nonlinear potential:
  G_t(theta)=sum_{i<t} h(theta^T x_i),
  h(z)=log cosh(z/2).

If a polynomial P_m approximates h uniformly on [-L,L] with per-factor error
eta_m, then
  sup_theta |G_t-Ghat_t| <= t eta_m,
and oscillation is at most 2 t eta_m.

To obtain aggregate oscillation O(1/t), it suffices to require

  eta_m = O(1/t^2).

Earlier O(t^-2) predictive control via global density-ratio arguments required
roughly eta=O(t^-3). So corrective oscillation saves one power of t.

## Degree consequence

Because h has nearest complex singularities at distance pi from the real axis,
uniform polynomial approximation on [-L,L] has geometric rate of the form

  eta_m <= C(L,m) exp(-Theta(m/L)).

Ignoring/polynomially controlling prefactors, eta_m=t^-2 requires

  m=O(L log t)=O(BR log t),

the SAME asymptotic degree order as eta=t^-3; only the constant multiplying
log t improves.

Therefore polynomial truncation degree was never the main obstacle.

## Explicit tensor state remains the bottleneck

The exact additive state for the degree-2m surrogate contains symmetric
moments through order 2m:
  S_k=sum_i x_i^{tensor k}.

Its dimension is
  sum_{j<=m} binom(d+2j-1,2j),
which is not poly(d,m) for variable d.

## Sketch accuracy

A sketch must approximate the AGGREGATE surrogate potential to absolute
oscillation O(1/t).

For a generic Monte-Carlo/JL-style estimator whose error decays m_s^{-1/2},
absolute accuracy 1/t still requires polynomial-in-t sketch size unless the
variance itself shrinks with curvature/leverage or the approximation has
exponential convergence in sketch dimension.

Thus saving one power of t does NOT rescue ordinary random sampling.

## Current state of the frontier

What we have learned:
1. analytic approximation in scalar z is cheap: degree O(BR log T);
2. exact update closure is available through tensor moments;
3. explicit tensor dimension is too large in variable d;
4. generic random sketching/sampling has too-slow 1/sqrt(M) convergence for
   the required vanishing absolute error;
5. sequential recompression does not telescope generically.

Therefore the remaining problem is sharply:

  Can the high-degree symmetric tensor contractions generated by
  h(theta^T x) be represented deterministically or quasi-deterministically
  with EXPONENTIAL accuracy in representation size, while updates remain
  poly(d,B,log T)?

A generic TensorSketch does not provide this in worst-case absolute error.

Candidate next routes:
A. exploit low-rank structure of the accumulated tensor induced by a single
   scalar ridge function h;
B. use deterministic polynomial/rational feature constructions with
   exponential convergence;
C. prove a conditional fixed-d algorithm and clearly separate it from the
   variable-d open problem;
D. derive a lower bound for linear sketches of high-degree moment tensors,
   which could explain why the computational frontier remains hard.

Recommendation: next audit whether a FIXED-d theorem already gives a complete
O(poly(log T)) algorithm and whether that result is nontrivial/known. This can
produce a rigorous intermediate theorem even if variable-d remains open.
